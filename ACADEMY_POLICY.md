# XWD Engineering Academy — Publishing Policy

This repository is an independent, **public** learning website.

## Content boundary

- Publish only general educational explanations and fictional examples cleared for public release.
- Do not copy, sync, embed, link to raw files from, or publish content extracted from private company repositories without explicit authorization and review.
- Never include internal diagrams, BOMs, product specifications, customer names, private project parameters, credentials, or personal data.
- The GitHub Pages output and Git history are publicly accessible.

## Local data

- Learning progress is stored in the browser's `localStorage` under `xwd_academy_progress_v1`.
- No cross-device sync, account authentication, or server-side backup is provided.
- Clearing browser storage removes local progress.

## GitHub Pages setup

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then **Save**.
4. After deployment, test `https://ziyoung888-prog.github.io/xwd-engineering-academy/` on the company computer only if allowed by IT policy.

## Scope of this prototype

Three example lessons, one multiple-choice check per lesson, browser-local progress, and a basic 1/3/7/30-day review schedule. No automatic course generation or publication pipeline has been configured yet.
