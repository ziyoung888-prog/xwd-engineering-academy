MODULE 01

01 · 2分钟｜先修能力与诊断

本课承接现金流、预算、净资产、应急资金和延期付款等知识。先前课程已讲授，并不等于学习者已独立完成练习或通过测评。诊断：计划储蓄7000元不意味着净资产一定增加7000元；要核实实际交易、到期债务、资产估值和现金余额。本节进一步解决：当未来工资不确定时，如何协调现金储备、保险与风险投资？

MODULE 02

02 · 4分钟｜人力资本的风险调整现值

人力资本来自未来劳动收入，不等于可随时变现的银行存款。简化现值模型：H = Σ E(Yt)/(1+r)^t，其中Yt是税后、扣除职业必要成本后的可支配劳动收入，r是反映时间价值与风险的折现率。模型必须考虑失业概率、职业成长、退休期限、行业周期和收入与资本市场的相关性。虚构对比：两名工程师工资、现金均相同，但A所在行业在经济衰退时裁员更频繁，B收入更稳定；A的未来工资风险更高，不应仅凭年龄判断能承受更大股票仓位。未来工资现值是决策参考，不是今天可用于还债的现金。

MODULE 03

03 · 4分钟｜流动性约束与尾部风险

传统三至六个月应急资金是启发式规则，并非对所有人最优。应关注“现金什么时候会用尽”，而不仅是月末余额。简化投资上限：可动用现金－近期确定到期款－压力情景储备。压力情景可纳入失业期间必要生活费、住房变化、押金和医疗支出。进一步可定义资金短缺概率P(min(C1…CN)<0)。即使第3个月末余额为正，第1个月也可能因付款集中到期而断流，称为路径风险。没有可信的失业持续时间分布时，应做情景与敏感性分析，不编造个人失业概率。

MODULE 04

04 · 4分钟｜税后真实收益与现金流口径

统一比较口径：工资用实际到账金额，不能对已经扣除的费用再次扣减；投资比较税后、费用后、通胀后的购买力变化。纯教学假设：名义收益4%，假设有效税费合计20%（不代表任何中国金融产品的真实税率），通胀2.5%。税费后名义收益约3.2%，真实收益=(1.032/1.025)-1≈0.683%。所以“年化4%”不等于购买力增长4%。中国工薪族需要理解工资薪金预扣预缴、年度汇算、依法适用的专项附加扣除、社保公积金口径；具体税务待遇必须核实当期官方规则，不能将某个假设税率套到存款、基金和保险上。

MODULE 05

05 · 4分钟｜保险的经济学作用

保险的主要功能是转移低频高损失风险，而不是最大化投资收益。先梳理基本医疗、养老、失业、工伤等社会保障，再识别个人仍承担的风险。虚构例子：某损失发生概率0.5%，损失额20万元，期望损失1000元。但低期望损失不代表无需保障：一次20万元的支出可能使家庭财务崩溃。应考虑风险厌恶、保费、免赔额、免责、等待期、保额、续保和理赔条件。社会保险与商业保险也不能机械视为完全替代。所有概率均为教学假设，不代表任何个人真实风险。

MODULE 06

06 · 4分钟｜工资风险与投资组合相关性

只看股票、债券和现金的比例是不完整的。人力资本同样是经济风险敞口。如果劳动收入和所持行业股票在经济下行时同步受损，失业与资产下跌可能同时发生。即使股票种类很多，也可能没有分散同一个宏观风险因子。“年轻就应该满仓股票”忽略了短期到期款、住房安排、保险缺口、流动性和风险承受能力。更稳健的长期路径是：保障确定到期款与现金储备，识别重大损失风险，再对长期可承受波动的资金做多资产配置，并按风险约束再平衡。

MODULE 07

07 · 5分钟｜虚构案例与压力测试

某城市工程师税后月收入12400元，正常月支出4800元，当前可用现金28000元；未来60天有3000元确定到期款。假设失业后每月必要支出7200元，要求覆盖3个月，打算立即将10000元投入风险资产。基础储备=7200×3=21600元，基础投资上限=28000－3000－21600=3400元，因此立即投资10000元不满足约束。若再考虑2000元一次性搬迁或医疗冲击，压力情景投资上限=28000－3000－21600－2000=1400元。假设现金工具预期年收益1.5%、风险投资预期年收益6%，在10000元上预期差约450元/年（未计税费和风险）；这个不确定收益不能保证弥补被迫低价卖出时的损失。决策反转条件包括：现金更多、到期款减少、失业成本降低、保障充分或风险资产的短期流动性更可靠。案例所有数字均为虚构，不对应任何人的真实账本。

基础投资上限：28,000 − 3,000 − 7,200×3 = 3,400 元
压力投资上限：3,400 − 2,000 = 1,400 元
